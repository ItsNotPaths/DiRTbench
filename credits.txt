Third-party data, checked in and embedded:
  assets/d3/schemaDirt3.xml           Ego-Engine-Modding
    The DiRT 3 database layout. src/d3/database.odin reads database.bin
    through it. Taken as-is from
    github.com/EgoEngineModding/Ego-Engine-Modding,
    src/EgoDatabaseEditor/schema/schemaDirt3.xml

Our own, but describing DiRT 3, and embedded:
  assets/d3/codriver/*.txt
    What each recording in a venue's stock speech bank says. Clip ids are the
    game's; the transcriptions are ours, from two whisper passes reconciled by
    ear. No game audio here, only names and text.

  assets/d3/palettes/*.txt
    Which stock texture and collision names a venue's road, ground and tarmac
    use. Names only, no texture payload.

Work we learned from. No code of theirs is in the binary:
  Grid2Bypass                         ismellyu
    The GRID 2 code self-check and its bypass, which mapped the same check in
    DiRT 3. github.com/ISmellYu/Grid2Bypass

  NefsEdit / NefsLib                  Victor Bush
    The NeFS archive layout that src/nefs reads and edits, with DiRT 3's
    public header key. github.com/victorbush/ego.nefsedit

Not embedded, and not in the repository:
  pacenotes/*.ogg                     Deuterium, the Sentient Mattress
    The co-driver voice, recorded for dirtbench. Read at startup from a
    `pacenotes` directory beside the binary, if one is there. Without it the
    pace-note preview stays quiet and the rest of the tool works.
    youtube.com/@DeuteriumtheSentientMattress

  assets/d3/moosylvania-materials.pssg
  assets/d3/water-materials.pssg
    DiRT 3 shader metadata and texture names cut out of two stock venues, kept
    as test fixtures. No texture or geometry payload. Reached only from
    _test.odin files, which `odin build` does not compile.

dirtbench ships no DiRT 3 art, audio, geometry or level data. A venue's art
comes out of the player's own install at export time, into content-packs/.
